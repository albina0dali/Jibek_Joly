JOL — исходный код сайта, версия 4

Состав проекта:
web/ — интерфейс, 3D-коридор, симуляция, диаграммы и отчёты.
server/ — серверные API, поток SSE, сохранение истории и настройки.
db/ и drizzle/ — схема базы данных и миграции.
scripts/ — сборка сайта и подготовка демонстрационной поездки.
tests/ — серверные проверки.

Добавление в существующий репозиторий:
1. Распакуйте папку jol-station внутрь локальной папки вашего репозитория.
2. Откройте PowerShell в папке вашего репозитория.
3. Выполните:
   git switch -c add-jol-site
   git add jol-station
   git commit -m "Add JOL railway simulator"
   git push -u origin HEAD

Установка и сборка из папки jol-station:
   npm ci
   npm run build

Сайт использует сервер Cloudflare Workers-совместимого формата и базу D1.
Открытие index.html двойным щелчком не запускает весь сайт.
Для сервера нужна привязка DB и переменная ADMIN_EMAIL для роли администратора.
Значения секретов, пароли, node_modules и Git-история в архив не включены.
Файл .openai/hosting.json содержит идентификатор уже опубликованного сайта Sites.
Добавление исходников в GitHub само по себе не публикует новую версию сайта.
